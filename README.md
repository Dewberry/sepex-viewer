# sepex-viewer

Prototype Dashboard for [sepex](https://github.com/Dewberry/sepex)

**Home**: Real-time job monitoring dashboard with 24-hour bar chart, status filtering, search, and KPI metrics

![](imgs/dashboard.png)

**Monitor**: Detailed job management table with submit/dismiss controls and job status tracking

![](imgs/monitor.png)

**Manage**: Browse available processes with submission forms for launching / dismissing  jobs

![](imgs/manager.png)
